# Code of Conduct

## TL;DR

> Critique the code, not the person. Assume good faith. Stop when asked.

This project is part of the NorteIA / Forja de Camaleones ecosystem. Everyone
is welcome to contribute — operators, juniors, students, alumni from FUNDAE
training, freelance reviewers. The bar is technical merit and respectful
collaboration; nothing else.

## Our standards

Behaviour we expect:

- Discuss tradeoffs, edge cases, and dissenting design choices without making
  it personal.
- Use Spanish or English freely — both are first-class in this repo.
- Cite sources when claiming "BORME does X" or "AEPD returns Y" — the skill
  lives or dies on official-source accuracy.
- Acknowledge prior art (other operator's contracts, blueprints, adapters)
  rather than rewriting from scratch.

Behaviour we do NOT accept:

- Personal attacks, insults, slurs, harassment.
- Discriminatory language on any axis (gender, age, origin, religion, etc.).
- Sustained derailing, brigading, or pile-on against a contributor.
- Sharing private information of other contributors without consent.
- "Rewriting works" PRs that ignore the operator's stated doctrine
  (cero Google/Apollo, self-hosted máximo, GDPR-first) — this is a technical
  decision, not a style one, and reverting is not a CoC issue but please
  read CONTRIBUTING.md before opening.

## Scope

This CoC applies to issues, PRs, code reviews, commit messages, the GitHub
discussions tab, and any synchronous channel where this repo is the topic
(call, screen-share, etc.).

## Enforcement

Reports go to **conduct@norteia.es** (email, ASCII). Maintainer (Luis Salgado)
will respond within 5 working days. Possible outcomes, not in order:

1. Private clarification / no action.
2. Public correction in the relevant thread.
3. Time-out from the repo (1 week to 3 months).
4. Permanent ban from the repo and its contribution channels.

Decisions are recorded in a private file. Repeat patterns escalate.
